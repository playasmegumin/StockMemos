### 可能存在冲突的代码

| 代码前缀 | 冲突说明 |
|----------|----------|
| **000/001/002/003** | **通常是深交所主板A股**，但 **000001–000099 区间** 与上交所指数代码重叠（如000001上证指数 vs 000001平安银行；000016上证50指数 vs 000016深康佳A） |
| **0（其他区间）** | 009/010/019/020/050 等原为上交所国债/指数代码，排除债券后，**050等指数代码**仍可能与深交所个股冲突 |
| **8（非82/83/87/88/92）** | 北交所个股占用82/83/87/88/92，其余8开头（如888880）为上交所标准券/备用，**区间不重叠，冲突极低** |
